Clean Data — split multi-value cells into rows

Already have a column where one cell holds several values joined by a separator? Split it here — no AI analysis and no API key needed. Runs entirely in your browser.

Separate several with a space: || | ;
Pairs the first value in each column, then the second, and so on using the same separator. By default, both columns must have the same number of parts in each row. Repeated values and blank positions are kept. Other columns are copied to each row. The new name applies to the first column only.
Optional: copies its entire original cell to every row created by the first column. Rows with matching counts still split into pairs.
