Medical Translation (ICD-11): map each row of a column to ICD-11 (and optionally a derived ICD-10 code). Make sure your WHO ICD Client ID & Secret are set in API Settings. An OpenAI API key (optional) improves disambiguation of free-text input.
Jev Classification: for each row, Jev picks one label from a list you define — it cannot return anything outside that list, and it reports how confident it is. Best for coding feedback, triage and categorisation where the categories are already fixed. Set your Jev API Key in API Settings. Define the lists on the next configuration step.
Clean Data: upload a file, pick the column whose cells hold several values, and split it into one row per value. Runs entirely in your browser — no AI, no API key, and nothing is sent to a provider.
